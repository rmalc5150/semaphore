# Market data downloads for the first of each month

Run this review with Codex on the first calendar day of each month in UTC. Use the latest complete period the publisher has released. Keep the publication date and the covered observation or filing period with each file. For quarterly and annual sources, check for a new release or revision and download it when it changes.

Give Codex the source ID, provider URL, original filename, publication or revision date, covered period and selections. Codex can validate the file, save the original under the historical-exports S3 prefix, commit parsed rows and return the Athena count and query ID. Record the month as checked if the provider has no new release.

The SEDI archive covers filing dates through December 2025. On the first monthly run, also collect January through October 2026 in separate monthly PDFs if available. The regular December 1 pull covers November 2026. The SEDI importer accepts a PDF or a ZIP of PDFs with distinct filing windows. Run `.venv-athena/bin/python sedi_archive_import.py /path/to/report.pdf --publish-and-queue` from the collection checkout.
