# Raw evidence and time fields

Reviewed 2026-11-22 13:23 UTC. This covers all **106** sources listed as having an unverified first raw publication date at the start of the review.

A qualifying original is the provider response or file containing data for the intended source. A full HTML report or registry detail qualifies when it contains the actual report or record. A search shell, job receipt, unrelated publisher document or curated copy does not establish provider provenance.

**105 sources** have a qualifying provider original in the samples checked. The Reddit route retains a curated corpus and no provider response was available. Three other routes already retained genuine originals under their native job records. Their earlier audit examples were a search shell, a different USPTO dataset and a CDS job response.

The verification runs for the four repaired routes yielded **five qualifying S3 originals**. All five are visible in Athena under query `4edee5e4-ead8-4231-a894-f6c878eed3fa`. The changes are deployed on the controller and C7. All four bounded historical jobs succeeded on their first attempt.

The earliest verified NMPA public disclosure date in the retained evidence from 2016 onward is **4 January 2016**. Nine trial pages give this date under the first public disclosure label. The committed-record search started on 1 January 2016 and ran under Athena query `d3888e1c-efc4-4def-8357-6182031dd0e8`.
